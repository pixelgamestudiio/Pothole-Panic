# Asset provenance

- All game artwork is original Canvas geometry in lib/game/components.
  The rickshaw, asphalt, potholes, people, trees, and shops scale without raster blur.
- Original app icons are generated by tool/generate_icons.py (Pillow required only
  when regenerating; the PNG outputs are already included).
- Original synthesized sound effects and engine ambience are generated by
  tool/generate_audio.py using Python's standard library. All WAV files are included.
- Bungee-Regular.ttf: Bungee by David Jonathan Ross, distributed under the SIL Open
  Font License 1.1. Full license is included at assets/fonts/OFL.txt.
  Source: https://github.com/google/fonts/tree/main/ofl/bungee
- Flutter's bundled Material icons are used for interface controls.
- Hindi catchphrases appear as text. No third-party movie clips or synthesized
  impersonations are included. Recorded character voices can be added later.

There are no missing image or audio placeholders; the game uses the assets and
vector components included in this repository.
